Loopwright

AI制作の失敗を、次の制作で使える品質管理の仕組みに変える開発基盤。その実演として、架空求人の制作ワークフローを動かすデモ。求人は検証用の題材で、製品そのものではない。

記録の再生 — リアルタイムの実行ではありません 架空データのみ 再検証の合格はデモ内プレビューの許可まで — 公開の許可ではありません

このページは、記録された実行と監査の再生です。ワークフローは、原本の固定 → FACT 抽出・照合 → 人間の承認 → LP 生成 → 独立した再検証、の順に進み、矛盾があれば生成せずに止まります。

1. 原本の固定→ 2. FACT抽出・照合→ 3. 人間の承認→ 4. LP生成→ 5. 独立した再検証
止まる例

原本 1,500円 に対して要約が 1,700円

原本の FACT（L03）
時給 1,500円
要約の記載
時給 1,700円

停止（矛盾あり）

E02 は照合で停止した。承認・生成・再検証・プレビューは実行していない。停止理由: 給与（時給）: FACT 時給1,500円（L03「給与は時給1,500円。」）に対し、要約は 時給1,700円。これは生成物ではなく、停止の記録の表示である。

監査で出力が変わった例

未記載項目の value を null に統一

ループ2の抽出では、未記載項目の value が実行ごとに「未記載」という文字列と空文字列で揺れた（監査の指摘）。改善実験（プロンプト v1.1）で「未記載項目の value は JSON の null とする」ことを指示文とスキーマ例の両方で明示し、未記載2件（renewal・housing）の value が null に統一された。以後の抽出の標準プロンプトとしている。詳細はリポジトリの experiments/exp-002-fact-extract-prompt-v1.1.md にある。
