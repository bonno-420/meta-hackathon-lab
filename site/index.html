Loopwright デモプレビュー

Loopwright は、AI の開発プロセスを記録・監査・人間の判断で回して改善する開発・実行基盤のデモである。架空求人の編集ワークフロー（原本の固定 → FACT 抽出・照合 → 人間の承認 → LP 生成 → 独立した再検証）を動かし、矛盾があれば生成せずに止まる。

進め方は本人と統括（Muse）の会話で決め、設計・監理（監査）・制作・書き込みの各ラインが分担した。受け入れの判断は本人と統括が行い、独立監査は監理ラインが担った。承認・確認・受け入れは人間の行為であり、自動化の成果と並べて示す。

止まる例: 原本 1,500円 に対して要約が 1,700円

E02 は照合で停止した（停止（矛盾あり））。承認・生成・再検証・プレビューは実行していない。停止理由: 給与（時給）: FACT 時給1,500円（L03「給与は時給1,500円。」）に対し、要約は 時給1,700円。これは生成物ではなく、停止の記録の表示である。

監査で出力が変わった例: 未記載項目の value を null に統一

ループ2の抽出では、未記載項目の value が実行ごとに「未記載」という文字列と空文字列で揺れた（監査の指摘）。改善実験（プロンプト v1.1）で「未記載項目の value は JSON の null とする」ことを指示文とスキーマ例の両方で明示し、未記載2件（renewal・housing）の value が null に統一された。以後の抽出の標準プロンプトとしている。詳細はリポジトリの experiments/exp-002-fact-extract-prompt-v1.1.md にある。
