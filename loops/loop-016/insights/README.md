# insights ストック

- ループ内で抽出した知見をためる置き場。台帳 (`docs/learnings.md`) への昇格は別途判断し、本ループは台帳を書かない
- 1知見 = 1ファイル `NNN.md`（`NNN` は 001 から連番）。`run-record.md` の「知見ストックの記録」表にも反映元・反映先とともに記録する

## 書式

```md
# insight-NNN: <要旨1行>

- 抽出元: C-X gen-N / review / memo（具体的なファイルパス）
- 日付: 2026-11-0x
- 知見: <何が起きたか・何が効いた/効かなかったか。実測に基づく>
- 反映先: C-Y gen-N+1 / 画像規格 / プロンプト
- 反映内容: <何をどう変えたか>
- 台帳昇格: 未判断（昇格時は判断日と理由を追記）
```
