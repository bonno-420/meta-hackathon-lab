# 知見・申し送り台帳

確定した知見と、監査・各パスからの申し送りを集約する台帳。散らばった記録（台帳の所感、監査レポート、exp）から「まだ反映されていないもの」を見失わないための受け皿であり、内容の正本は各出所の記録にある。

## 運用

- 追記は各パスの閉じ作業時に統括が行う。対象は、監査で確定した指摘・申し送りと、実験・実施で確定した知見のみ（推測や未確定の案は入れない）
- 棚卸しはマイルストーン時に統括が実施する（M2: 2026-10-30、提出前: 2026-11-02）。全行の状態と反映先を最新化し、反映済みは履歴として残す
- 状態の語彙: 未反映／対応中／反映済み／見送り
- ゲート化すべき知見はゲート候補として別途記録し（基本設計 v1.1 §7）、本台帳からは反映先として参照する
- ロードマップの宿題（Spend Limit 確認、Billing 突合、Official Rules 精読）は roadmap 側で管理し、本台帳には入れない
