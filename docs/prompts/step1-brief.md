## 依頼内容

確定版の工程1（10/28–29）の作業1–4を実施する。順序を分けて行い、混ぜない。

1. **再現性の把握（プロンプト v1 のまま）**: ループ2と同一条件で FACT 抽出を再実行し、抽出の一致とばらつきを記録する。プロンプトは変えない
2. **改善実験（プロンプト v1.1、1要因）**: 未記載項目の value の扱い（`null` と明示する）だけを変え、v1 の結果と比較する。手順と結果は exp-001 の流儀で `experiments/` に記録する
3. **スキーマ完全性チェックの追加**: 抽出結果のキーの欠落を検出するチェックを実装する。扱いはゲート候補として最小レコード（ID、版、検査対象、合否基準、由来、状態）で記録するまでに留め、昇格はしない
4. **承認対象の固定**: 採用した抽出結果（FACT）を版つきで固定する具体物を定義し、置く（再監査の観察事項 O3(a): 成果物ファイル、置き場所、版の識別子の付け方を定めること）
