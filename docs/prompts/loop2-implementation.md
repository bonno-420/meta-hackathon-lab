## 実装するもの

架空求人原本 FICT-J01 v1 を入力に、次を行う小さなプログラム。言語と構成は最小でよい（Node.js か Python の単体スクリプトと、その実行記録を想定）。

1. **原本の固定**: 下記の FICT-J01 v1（行ID L01–L06）を版つきデータとして保持する
2. **FACT 抽出**: 給与・勤務時間・交通費・勤務地・雇用形態などの項目を、出典の行IDと引用つきで構造化する。モデル呼び出しは Meta Model API（モデル `muse-spark-1.3-contributor`、ベース URL `https://api.meta.ai/v1`、API キーは環境変数 `MODEL_API_KEY` から読む）
3. **照合**: 別の概要テキストと FACT を突き合わせる。矛盾があれば、両方の値と出典位置を示し、「照合」の工程で停止する（先に進めない）
4. **評価の実行**: E01 と E02 を実行し、期待結果と実出力を並べて記録する
   - E01: FICT-J01 v1 をそのまま照合 → 記載項目は一致。更新と寮は未記載。人間承認前には生成を開始しない（生成工程は作らない）
   - E02: 別の概要に「時給1,700円」とある入力 → L03（時給1,500円）との給与矛盾を提示し、照合で停止する
5. **記録**: `loops/loop-002/` に、入力版、使用モデル、プロンプト版、出力、判定、トークン量と実費、所要時間を残す（記録仕様は basic-design に従う）
