# 決定記録 D3: 最小実証の範囲

- 決定日: 2026-10-27
- 決定者: 本人
- 状態: 決定済み
- 典拠: `docs/design/review-notes-v1.md` の候補 A、D1（提出物は統合デモ）

## 決定

最小実証は **候補 A** とする。

- 題材: 架空原本 **FICT-J01 v1 の FACT 照合のみ**
- 評価: **E01 と E02 の2件**
  - E01: FICT-J01 v1 をそのまま照合する。記載項目は一致し、更新と寮は未記載として扱う。人間承認前には生成を開始しない
  - E02: 別の概要に「時給1,700円」とある入力に対し、L03（時給1,500円）との給与矛盾を、両方の値と出典位置を表示して照合で停止する
- 工程は 要件確認 → 設計 → 独立監査 → 実装 → 成果物監査 までを1周回す
- LP 生成はこの周回に含めない

## 根拠

- D1 の統合デモの最初の縦切りになる
- 正常系（E01）と「矛盾で止まる」系（E02）の両方を含み、基盤の核である照合・停止・記録を最小コストで検証できる
- 候補 B（基盤ツール先行）は成果の具体性が遅れる。候補 C（E01–E10 一括）は最初の1周が重すぎる

## 影響

- ループ2は本範囲の実装を対象とする
- E03–E10 は後続の周回で順に扱う
- 準備資料にある FICT-J01 と評価セットの定義が正本であり、本決定はその範囲指定である（定義自体は変更しない）
