# D6: 提出リポジトリ

- 決定日: 2026-10-27
- 決定者: 本人
- 状態: 決定済み

## 決定

提出リポジトリは現行の `meta-hackathon-lab` をそのまま使う。改名も新規作成もしない。

## 理由

- 本人判断による（2026-10-27。「デメリットがなければ現行でよい」）
- 監査の観点（N12）では、改名・新規作成は Git 履歴の連続性と、期間内作成であることの証跡を弱める方向に働く。現行維持はそのリスクを避けられ、実質的なデメリットは見当たらない

## 補足

- リポジトリ名が汎用的である点は、提出時に README と提出文面でプロジェクト内容を明確に示すことで補う
