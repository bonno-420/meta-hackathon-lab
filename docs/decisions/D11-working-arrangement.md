# D11 開発体制（OpenCode の各ラインによる分担）

- 日付: 2026-10-28
- 決定者: 本人

## 決定

- 設計・監査・書き込み・制作は、OpenCode の各ライン（設計ライン・監理ライン・書き込み用ライン・制作ライン）が担う。
- 進行統括と指示出しは、本人と統括（Muse）の会話で行う。統括は依頼の切り分けと配分、成果物の検証、記録（決定記録・台帳・ロードマップ）の維持を担う。
- 受け入れの判定は、本人と統括が行う。
- D9（Muse Bot が自ら実装まで担う形）は 2026-10-28 で終了する。D9 は工程1〜3で有効だった（監理ライン監査「修正」→再監査「合格」を経て本人が受け入れ）。
- 本体制は工程4から適用済みであり、本記録はその追認と明文化である。

## 影響

- `AGENTS.md` の Mission と「モデルと記録」の記述を本決定に合わせて修正した。
- モデルと役割の割当そのものは D4 と `docs/model-selection.md` の台帳に従う（本決定では変更しない）。

## D9 との対応

- 終了: D9 の決定内容 1（開発の主体は Muse Bot）、および 4・5 のうち実施主体に関する部分
- 存続: D9 の決定内容 2（コミット・課金・外部送信は本人の明示承認時のみ。D8 と一体）、決定内容 3 の監査と受け入れの枠組み（独立監査は監理ラインが担い、受け入れは本人と統括が行う）、決定内容 6（製品（L2）の実行時モデルは Spark 1.3 系のまま変更しない）
- 本対応表は全体監査（2026-10-28）の指摘により追加した
