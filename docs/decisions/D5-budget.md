- 状態: 決定済み（改訂可）

## 前提の枠（開始前準備資料を継承）

- Meta Model API クレジット $150 のうち、実使用枠 $100 ＋ 予備 $50
- 累計 $75 で新規探索を停止する。新規探索とは、未確定の設計・モデル・手法の試行をいい、確定済みの実装と再検証は含めない（basic-design v1.1 §10）
- 同時実行 1 件、自動再試行なし

## 実使用枠 $100 の配分

| 区分 | 上限 | 内容 |
|---|---|---|
| 製品実行 | $15 | L2 の推論（FACT 抽出、照合、LP 生成、再検証）。主に Spark 1.3 系 |
| 設計・監査 | $35 | Wonder の設計起点と監査パス |
| 実験 | $25 | 改善実験、再現性検証、exp-001 の計測に伴う実行 |
| 未割当バッファ | $25 | 想定外の再実行や追加パス。用途が決まったら上記区分へ振り替える |

## 運用ルール

- 区分の上限を超えそうな場合は、その時点で本人に確認する。他区分から自動で流用しない
- 予備 $50 は、本人の明示承認がある場合のみ使用する
- 実費は同一台帳・区分列で記録し、dev.meta.ai の Billing 実績と突き合わせて確定する（算出値のまま確定扱いにしない）

## 根拠（実測）

- ループ2の実測: FACT 抽出 1 回 $0.001289（Spark 1.3 Contributor）。Spark 系の消費は誤差レベルで、コストの中心は Wonder のパス回数になる
- 決定時点の累計消費は $0.01 未満であり、枠には十分な余裕がある。本配分は使い切りの目標ではなく上限管理である
