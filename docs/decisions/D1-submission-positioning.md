# 決定記録 D1: 提出物の位置づけ

- 決定日: 2026-10-27
- 決定者: 本人
- 状態: 決定済み
- 典拠: `docs/project-instruction-v1.md` §1、`docs/design/review-notes-v1.md` の C1 / D1、ループ1設計監査レポートの推奨順序（D1 を最初に決める）

## 決定

提出物は **統合デモ** とする。

AI 開発・実行基盤（L1）が、編集ワークフロー（L2: 架空求人の FACT 照合パイプライン）を実行するデモを提出物とする。デモでは、基盤側の工程と記録（設計・監査・実行・改善）と、ワークフロー側の成果（照合、矛盾での停止、人間承認、再検証）の両方が見える形にする。

## 根拠

- 審査配点（Impact 30% / Use of Meta AI Tooling 25% / Technical Depth & Execution 20% / Demo 25%、context-pack-v1 参照）に対して、統合形は「具体的な成果」と「仕組みの新規性・深さ」を 1 本のデモ動画（3 分）で両方示せる
- 開始指示の基盤構想と、応募資料のプロダクト設計の両方を、正本として維持したまま両立できる
- 最小実証（候補 A: FICT-J01 の FACT 照合、E01・E02）が、そのまま統合デモの最初の縦切りになる

## 却下した選択肢

- **基盤のみを提出物とする**: 仕組みの説明が中心になり、デモの具体性と説得力が弱い
- **編集デモのみを提出物とする**: プロセスを評価・改善する仕組みが提出物に現れず、開始指示の主目的が伝わらない

## 影響

- review-notes の C1（提出物の位置づけ未定義）は本決定で解消する
- 準備資料（期間前の計画書）は既存物であり、提出物には含めない。デモは期間内の新規作成物のみで構成する
- 後続の判断（D3 最小実証の範囲、D5 予算配分）は本決定を前提に進める
