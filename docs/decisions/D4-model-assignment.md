# 決定記録 D4: モデルと駆動環境の割当

- 決定日: 2026-10-27
- 決定者: 本人
- 状態: 決定済み
- 典拠: `docs/project-instruction-v1.md`（モデルと役割の割当は名称で決めず、利用可能な機能と費用を確認してから決める）、2026-10-27 の実測（OpenCode から `muse-spark-1.3-contributor` と `muse-wonder-1.0` の双方を呼び出し可能と本人が確認）

## 決定

- 駆動環境（コックピット）: **Codex（主）/ OpenCode** とする。VS Code は閲覧・差分確認用に格下げし、起点にしない。Muse Code の利用は必須としない
- 実装・制作ラインの主力モデル: **Muse Spark 1.3 Contributor**（`muse-spark-1.3-contributor`、Meta Model API）
- 設計の起点と監査の要所: **Muse Wonder**（`muse-wonder-1.0`）。常時投入ではなく、投入箇所を選ぶ
- デモ製品（L2）の実行時判定: Muse Spark 1.3 系（Contributor 可）

## 根拠

- `muse-spark-1.3` と `muse-spark-1.3-contributor` は同一モデルで、公開スペック（コンテキスト長、推論段階、ツール呼び出し、構造化出力）は同一（2026-10-27 に公開情報で確認）。差は価格（100万トークンあたり入力 $1.25 対 $0.10、出力 $4.25 対 $0.20）、レート制限（3,000 RPM 対 100 RPM）、データ利用（Contributor は入力と出力が製品改善に使われ得る）
- 本プロジェクトの開発で扱うのは架空データのみであり、Contributor のデータ利用条件が実害にならない
- Wonder は Contributor 形態がなく単価が高い（入力 $4 / 出力 $20）ため、要所への投入とする
- 駆動環境は、本人の作業テンポ（GUI のエージェント環境から任せる進め方）に合わせる。Git の操作はエージェントが行い、本人は判断と承認に寄せる

## 影響

- D5（予算配分）は本決定の単価を前提に決める
- 監査ラインも同じ駆動環境で回してよい。独立性は文脈パックとプロンプトの分離で担保する
- 実在の求人・企業・個人の情報や実コードを Meta Model API に送る作業は、本決定の対象外であり行わない

## 追記2（2026-10-27）: 主・サブの運用（コスト感）

- 既定の流れは「サブ（Muse Spark 1.3 Contributor）が実施と一次確認まで行い、Wonder が監査・判断する」。Wonder は原則として自分では作業しない
- 差し戻しが重なる場合は、修正回数とコストの見合いで、Wonder が直接実施に切り替える
- 運用方針の現行版は `docs/model-selection.md`（知見台帳）の「現在の方針」に置き、実測を貯めて見直す

## 追記3（2026-10-27）: 作業統括と作業員の体制

- ライン側の体制は、作業統括 = Muse Wonder、作業員 = Muse Spark 1.3 Contributor とする
- Wonder は、作業の分解、作業員への文脈の供給、指示、成果の取りまとめと一次品質管理を行い、原則として自分では実装しない。差し戻しが重なる場合は、修正回数とコストの見合いで直接実施に切り替える
- 統括（Muse）は依頼と受け入れ条件を提示し、成果物のチェック（監査判定）と記録を本人と一緒に行う。Wonder は自ら統括した作業に最終の合格を出さない
- 現行方針の詳細は `docs/model-selection.md` の台帳を参照する

## 追記4（2026-10-27）: 起点とライン別統括の体制

- オーケストレーションの起点は統括（Muse）に置く。Muse が依頼を切り分けて各ラインへ配分し、成果物の受け入れチェックと監査判定、記録を本人と一緒に行う
- ラインは設計、管理（監査と進行・ゲート管理）、制作に分け、各ラインに作業統括として Muse Wonder を置く。セッションもラインごとに分けて開く
- 各ラインの Wonder は、作業の分解、作業員（Muse Spark 1.3 Contributor）への文脈の供給、指示、取りまとめと一次品質管理を行い、原則として自分では実装しない
- Wonder は自ら統括した作業に最終の合格を出さない。現行方針の詳細は `docs/model-selection.md` の台帳を参照する
