## What the user wants to build

A tool. You hand it a job posting; it scrutinizes the posting, and a complete LP — text, images, and assembly — comes out.

It is a tool, not a session's performance: the same input gives the same result whoever runs it, without depending on who is operating it that day. The scrutiny is the point as much as the output — the posting is checked against its own facts, contradictions stop the run instead of being smoothed over, and what the source does not state is never invented. A human approves the facts before anything is generated, and the finished page is checked again before it counts as done.

The platform around the tool is how it was built and kept honest: AI does the work, every step is recorded, audits check the work against the records, and humans keep the judgement. The job-posting workflow is the demonstration that the tool — and the way it was built — actually works.
