## 2. 誰に訴求するか（対象層とペルソナ）

### 主対象（来てほしい人）

- 夜勤（21:00〜翌6:00）を前提に働ける人。昼夜逆転が可能で、体を動かす作業をいとわない人
- 普通自動車免許（AT限定可）を持っている人 ※必須のため入口で明示する
- 未経験からの開始を希望する人（フォークリフト免許がなくても応募できる）
- 次のいずれかに当てはまり、深夜帯の勤務に見合う理由がある人
  - 深夜割増を含めた時給で固めて稼ぎたい人
  - 緑川駅からの送迎バスや単身寮を使いたい人（車通勤・転居を避けたい人）

### 想定ペルソナ（2名）

- P1「夜で稼ぐ型」（優先）: 20〜30代、製造・軽作業・配送補助などの経験あり／なし。日中の予定より手取りを優先する。免許あり。寮・送迎の有無で応募可否を判断する
- P2「始めやすさ重視型」（副次）: 物流未経験。フォークリフト免許なし。仕事の覚えやすさ（仕分け・ピッキング中心）と、送迎・寮・社保の有無を重視する

### 対象外として扱う人（LP内で早期に自己除外してもらう）

- 日勤希望の人、21:00〜翌6:00に働けない人
- 普通自動車免許がない人（必須のため、応募条件の先頭で明示する）
- 3か月更新の有期・賞与なしが受け入れられない人（長期の正社員保障を求める人）
- 敷地内での喫煙を求める人（原則禁煙のため）

狙い: 応募数を膨らませる企画にしない。対象外の人が最後まで読んで誤応募する構造を避け、入口と条件セクションで自己判断できるようにする。

## 3. 何を軸に訴求するか（企画の核）

### 推奨軸（A案・推奨）

**「夜に働く条件を全部開く。納得したら応募する」**

- 主張: 夜勤・有期・残業・寮・送迎・禁煙を隠さず並べ、深夜割増と勤務時間・休日の事実で判断してもらう
- なぜこれか:
  - 原本の強みは「時給1,550円＋深夜25%割増」「21:00〜翌6:00・実働8時間・週2休（日曜＋1日）」「送迎・単身寮・社保」という具体条件であり、抽象的な魅力語に逃げずに済む
  - 弱み（夜勤・有期3か月・賞与なし）も原本の事実であり、隠すと面接辞退・早期離脱の原因になる。開示型の方が調整材料（制作能力の測定）に適する
- 副軸（支え）: 「未経験可＋免許条件の明確化」「日曜固定休＋シフト1日の見通し」「フォークリフト免許保有者への相談導線（運転志向の受け皿）」

### 対立軸（B案・不採用を推奨）

**「稼げる・楽・安心」を前面に出す煽り型**

- 不採用理由: 「月収例28万円程度」は試算・保証ではないため、見出しで断定すると原本逸脱になる。賞与なし・有期という事実と衝突し、Claim-Evidence対応が崩れる

### セクション骨格（文章・コピー自体は承認後に作る。見出し案の提示ではない）

1. 冒頭: 夜勤であること＋免許必須を最初に示す（対象の自己選別）
2. 稼ぎ方: 時給・深夜割増・勤務時間・月収例（試算・保証ではない旨を併記）
3. 休み方・働き方: 週5日・週2日（日曜＋シフト1日）・残業月10時間程度
4. 契約の形: 3か月更新（勤務態度と業務量による）・試用1か月同条件・賞与なし・退職金なし・社保完備
5. 住まいと通い方: 単身寮（月15,000円・光熱費別・審査あり）・緑川駅間の送迎バス
6. 仕事内容と現場ルール: 仕分け・ピッキング・積み込み・台車／小型車両の移動、敷地内原則禁煙
7. 応募条件: 普通免許必須（AT可）・未経験可・フォークリフト尚可
8. 応募への誘い: 条件を確認した上での応募であることを明示

注記: 上記は順序と役割の設計であり、訴求文の先書きではない。承認後に各セクションの訴求文を作る。

## 4. その条件をデメリットに感じる読み手はどう扱うか

方針: デメリットを言い換えで薄めない。事実のまま early disclosure し、読み手が降りられる出口を作る。

| 原本の条件 | デメリットに感じる読み手 | 扱い（企画段階の決定） |
|---|---|---|
| 夜勤 21:00〜翌6:00 | 昼夜逆転が無理・体力不安・家族都合 | 冒頭で夜勤であることを明示する。体力面の断定（楽・慣れる等）はしない。昼間の過ごし方・睡眠確保の助言は原本にないため書かない |
| 有期3か月・更新は勤務態度と業務量による | 長期安定を求める人 | 「更新あり」だけを切り出さない。期間3か月＋更新条件（勤務態度と業務量による）を一文で併記する。更新率・実績は原本にないため書かない |
| 賞与なし・退職金なし | 年収・長期報酬を重視する人 | 稼ぎ方セクションとは別に契約セクションで明示する。時給・月収例で相殺された印象を与えない配置にする |
| 月収例28万円程度（試算・保証ではない） | 額面を保証と誤読する人 | 「試算・保証ではない」を省略しない。内訳の再計算（休憩位置・深夜時間の配分など）は原本にないため独自内訳を作らない |
| 残業 月10時間程度 | 残業不可の人 | 「程度あり」を明示し、残業ゼロの断定はしない。繁閑の波・月による変動は原本にないため書かない |
| 寮 月15,000円・光熱費別・審査あり | 誰でも入寮できると思う人 | 「誰でも」「格安」等の評価語を使わない。金額・単身用・光熱費別・審査ありを4点セットで示す。空室・入寮時期は原本にないため書かない |
| 送迎バス（緑川駅間） | 運行時間・本数が気になる人 | 「送迎バスあり」の事実のみ。運行時間・本数・所要時間・予約要否は原本にないため書かない（時刻表の創作禁止） |
| 敷地内原則禁煙 | 喫煙する人 | 応募条件付近または現場ルールで明示する。喫煙所の快適さ等の補足はしない |
| 普通免許必須（AT可） | 免許がない人 | 冒頭と応募条件の両方で必須として示す。「取得見込み可」「相談可」は原本にないため書かない |
| 日曜＋シフト1日の週2休 | 土曜休み希望・連休希望の人 | 日曜固定＋もう1日はシフトであることを明示する。連休・希望休の通りやすさは原本にないため書かない |
| 未経験可／フォークリフト尚可 | 手を動かすより運転がいい人・免許を活かしたい人 | 「優遇・手当あり」「フォークリフト業務あり」と断定しない。運転志向の読み手のメリット受け皿として「フォークリフト免許をお持ちの方は業務の範囲についてお問い合わせください」という相談導線にする。資格手当・配属確約・運転時間の割合は原本にないため書かない |

共通ルール: 原本にない数値・頻度・実績・雰囲気（楽・きれい・人間関係が良い等）は一切足さない。評価語を使う場合は原本の数値と対にする。

## 5. 原本の事実で言えること・言えないこと

### 言えること（原本の範囲内。表現は承認後に作る）

- 時給1,550円、深夜（22:00〜翌5:00）は25%割増であること
- 勤務時間 21:00〜翌6:00、休憩60分、実働8時間であること
- 週5日勤務、週2日休み（日曜＋シフトで1日）であること
- 残業は月10時間程度あること
- 契約は3か月、更新あり（勤務態度と業務量による）こと。試用期間1か月（同条件）こと
- 賞与なし、退職金なし、社会保険完備であること
- 自社寮あり（単身用、月15,000円、光熱費別、入寮審査あり）こと
- 緑川駅との間に送迎バスがあること
- 敷地内原則禁煙（休憩所の喫煙スペースのみ可）であること
- 普通自動車免許（AT限定可）必須、未経験可、フォークリフト免許は尚可であること
- 仕事内容が仕分け・ピッキング・積み込み・構内での台車／小型車両の移動であること
- 月収例28万円程度は「月20日・残業10時間の試算」であり「保証ではない」こと（注記必須）

### 言えないこと（原本にないため書かない。承認があっても書かない）

- 月収の保証・最低額・平均額・「稼げる」の断定。深夜時間の独自按分による再試算
- 更新率・正社員登用の有無・長期雇用の約束（「安定」「長く働ける」の断定を含む）
- 賞与・退職金に代わる手当の存在、資格手当・皆勤手当などの創作。フォークリフトの業務確約・運転割合・配属先の断定
- 寮の空室・入寮時期・部屋の広さや設備、光熱費の金額、審査基準の推測
- 送迎バスの時刻・本数・所要時間・バス停の詳細
- 休憩時間の取り方・仮眠の可否、夜勤の楽さ・慣れやすさ、職場の雰囲気・人間関係
- 副業可否、土曜休み・連休・希望休の運用、シフトの自由度
- 車通勤の可否・駐車場の有無、駅からの徒歩時間、周辺環境の利便性
- 応募から入寮・入社までの日数、面接回数・選考フロー

### 表現上の禁止（本案件の制作フェーズに適用）

- 「高収入」「ガッツリ稼げる」「安心の正社員並み」等の断定・誇張
- 「誰でも入寮可」「格安」「駅チカ」「アットホーム」「楽な作業」の創作評価語
- 月収例の注記（試算・保証ではない）の省略・脚注への追いやり
- 「更新あり」だけの切り出し（更新条件の併記を必須とする）
